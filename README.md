# Dotfiles

My developer tool and program configuration files for a modular and 
portable environment. Managed by GNU Stow.

## My daily workflow

### Browser

Google Chrome. It spies on you constantly. It works. Good developer tools.
Doesn't crash all the time.

### Terminal

Ghostty. It looks good and has the best balance of speed, features and
standards.

### Text Editor

Neovim. I don't want a million popups blocking my work and interrupting my train
of thought. I have a minimal setup that _works for me_. See [my GitHub
repo](https://www.github.com/josh-guzman/nvim) for details.

### Music

Spotify. It can be slow and annoying but it works and that's what I'm used to.

### Window Manager

Aerospace. MacOS does not offer a window management system that was built for
power users. This app was and does. It works. It's keyboard-driven and very
fast. Still some bugs but 1000x better than the default options.

Raycast. Raycast has built-in window management but is not automatic and does not offer
as many features. I used it and it works well but Aerospace is better.

### Note-taking

Obsidian. I want to have access to my files at all times. Obsidian just looks on
your computer for plain text (markdown) files and renders them in a pretty
format. I own my files. If Obsidian stops existing tomorrow, I can still take
notes in a different app (or even better, in my [Text Editor](###text-editor)!)
Notion does not offer that capability because it stores your notes in a
proprietary database format.

### Todo App

A plain text called `todo.md`. No further explanations.
